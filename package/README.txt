PSEUDONYMISATION
================

INSTALLER
  Copiez le dossier « App-Pseudonymisation-TKS » sur votre clé USB. C'est tout.

LANCER
  Windows : double-clic sur App-Pseudonymisation-TKS.exe
            (si un avertissement apparaît : « Informations complémentaires »
             puis « Exécuter quand même »)
  Mac     : double-clic sur Lancer-Mac.command
            (la première fois : clic droit, « Ouvrir », « Ouvrir »)

  Le navigateur s'ouvre sur l'application. Laissez la fenêtre noire ouverte.

PREMIÈRE FOIS
  Choisissez un mot de passe.
  ATTENTION : s'il est perdu, les données sont perdues. Notez-le en lieu sûr.

UTILISER
  + Nouveau participant : saisir une personne (un ID lui est attribué).
  Exporter : « Pseudonymisé » pour vos analyses (sans nom ni contact).
  Importer : reprendre un ancien fichier Excel.
  Quitter : toujours fermer avec ce bouton.

SAUVEGARDES
  Automatiques, dans le dossier « backups » de la clé.
  Copiez régulièrement le dossier « App-Pseudonymisation-TKS » (ou l'ancien « Participants ») ailleurs.

METTRE À JOUR
  Si l'ordinateur a accès à Internet, un bouton « Mise à jour disponible »
  apparaît automatiquement dans l'en-tête de l'application.
  Cliquez simplement dessus pour installer la dernière version en un clic.
  Vos données (« data » et « backups ») et votre mot de passe sont strictement préservés.
